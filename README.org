#+TITLE: lean-poo

A modular Lean implementation of the functional prototype model in
[[https://github.com/metareflection/poof][POOF]]. [[https://github.com/tao3k/gerbil-poo][Gerbil-POO]] informs object-level implementation choices; Faré's
[[https://github.com/fare/c4-mixins][C4-Mixins]] is the reference for C4 linearization. Lean types, functions,
and thunks determine this project's API.

The [[file:docs/prototype-mvp.org][prototype MVP]] is the smallest executable paper-model entry point.
[[file:docs/prototype-computation.org][Generator and delayed computation]] form the next constructive layer.
[[file:docs/first-class-object.org][First-class objects]] retain a prototype with each lazy instance.
The [[file:docs/replication.org][implementation assessment]] maps the current PO construction to Lean modules,
an integrated C4-to-object execution path, and its remaining boundaries.
[[file:docs/usage.org][Usage]] lists the API; the
[[file:docs/use-case.md][use case]] shows object construction and evaluation.
