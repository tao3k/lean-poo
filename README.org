#+TITLE: LeanPoo
#+OPTIONS: toc:2

LeanPoo is a Lean 4 library for prototype-oriented object composition and
incremental proof reuse. Applications supply typed fields, operations and
obligations; the library composes their implementations and evidence.

The construction model follows [[https://github.com/metareflection/poof][POOF]] and
[[https://github.com/tao3k/gerbil-poo][Gerbil-POO]], with C4 resolution from
[[https://github.com/fare/c4-mixins][C4-Mixins]]. The
[[file:docs/audits/poof/README.org][paper audit]] distinguishes implemented typed
contracts from remaining research.

* Architecture

| Layer | Responsibility | Start here |
|-------+----------------+------------|
| =LeanPoo.Prototype= | Open-recursive construction, delayed instances, descriptors and mutable slots. | [[file:docs/prototype-mvp.org][Prototype model]] |
| =LeanPoo.C4= and =LeanPoo.Object= | Inheritance order, typed fields and methods, lazy reads, persistent revisions and dependency-aware reuse. | [[file:Examples/ObjectDefinition.lean][Typed object definition]] |
| =LeanPoo.Functional= | Context-indexed factories, capability selection, Contracts, certified consumers and shared preparation. | [[file:Examples/FunctionalPipeline.lean][Functional pipeline]] |
| =LeanPoo.Proof= | Proof objects, obligations, patches, invalidation and certificate closure. | [[file:Examples/ProofReuse.lean][Proof reuse]] |
| =LeanPoo.Deriving= | Typed dictionary conversion with kernel-checked inverse laws. | [[file:docs/contracts/dictionary-classes.org][Dictionary contracts]] |
| =LeanPoo.Object.Debug= | Bounded read tracing and recursive-read diagnostics. | [[file:Examples/DebugTrace.lean][Read tracing]] |

The usual flow is to declare typed operations, compose their owners, prepare
the selected capabilities, then consume the result at the current input.
Revisions retain only evidence whose declared dependencies still hold.
[[file:docs/usage.org][API usage]] gives the public entrypoints;
[[file:docs/reusable-contracts.org][reusable contracts]] helps choose the appropriate abstraction.

Shared C4 preparation belongs to an immutable graph owner; prepared consumers
and context caches belong to their declared input lifetime. Their refinement
laws preserve reference results and errors. Their first-use and retention costs
remain part of application performance; see [[file:Benchmarks/README.org][benchmarks]].

* Build and verify

Install the toolchain named in [[file:lean-toolchain][lean-toolchain]].

#+begin_src sh
lake build
just check
#+end_src

=lake build= builds the library. The complete =just check= gate also requires
Just, zsh, Python 3, Pandoc and a =timeout= command. Documentation uses Pandoc's
Org reader; source blocks are not executed. =just --list= lists focused checks
and native benchmark recipes. [[file:docs/check-performance.org][Check performance]]
explains worker limits and the distinction between local checks and CI.

* Reading paths

- *Using the library:* [[file:docs/usage.org][API usage]] → [[file:Examples/README.org][examples]] → [[file:docs/reusable-contracts.org][contract index]].
- *Understanding the model:* [[file:docs/prototype-computation.org][delayed computation]] → [[file:docs/first-class-object.org][first-class objects]] → [[file:docs/replication.org][implementation assessment]].
- *Studying extensions:* [[file:docs/contracts/generalized-prototypes.org][generalized prototypes]], [[file:docs/contracts/dataflow-objects.org][materialized field objects]] and the [[file:docs/audits/poof/functional.org][Functional paper audit]]. Related workflows and their individual contracts are indexed in Examples.
- *Evaluating performance:* [[file:Benchmarks/README.org][benchmark workloads and evidence boundaries]]. Focused algorithm gains do not establish whole-process latency or RSS improvements.

Kernel proofs establish the stated model laws. Native execution of unrestricted
open recursion may diverge; bounded diagnostics and process supervision apply
to their own entrypoints. Application authority, deployment effects and external
implementation refinement remain consumer responsibilities.
