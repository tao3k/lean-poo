#+TITLE: LeanPoo

LeanPoo is a Lean 4 library for prototype-oriented object composition and
incremental proof reuse. It implements the functional prototype construction
described in [[https://github.com/metareflection/poof][POOF]] with Lean's types, functions, and thunks. Its C4
linearization follows [[https://github.com/fare/c4-mixins][C4-Mixins]]. [[https://github.com/tao3k/gerbil-poo][Gerbil-POO]] informs the object-level design.

The library is domain-neutral: applications supply their own typed keys,
values, obligations, and dependency graph. It does not define a policy
language or a domain-specific proof system.

* What it provides

| Layer | Public capability |
|-------+-------------------|
| ~LeanPoo.Prototype~ | Open-recursive prototypes, ordered composition, delayed instances, first-class objects, and classes. |
| ~LeanPoo.C4~ and ~LeanPoo.Object~ | C4 precedence, typed slots, inheritance, override, mix, clone, lazy reads, persistent revisions, and checked incremental value and thunk reuse for finite dependencies. |
| ~LeanPoo.Proof~ | Proof objects, patches, obligations, dependency-based invalidation, certificate reuse, and closure. |
| ~LeanPoo.Object.Debug~ | Public bounded read tracing and recursive-read diagnostics for object development. |

Lean's type system expresses slot families and composition boundaries. The
general open-recursive fixed point is executable and may diverge; the debug
API bounds reads made through that API, while the example runner adds process
time and memory limits. The [[file:docs/replication.org][implementation assessment]] records the precise scope and
runtime boundary.

* Get started

Install the Lean toolchain named in [[file:lean-toolchain][lean-toolchain]]. Build the library with
~lake build~. The full project check uses ~just~, ~zsh~, Emacs for Org parsing,
and a ~timeout~ command:

#+begin_src sh
lake build
just check
#+end_src

The smaller Justfile targets include ~check-c4~, ~check-object~,
~check-proof~, ~check-debug~, and ~check-docs~. Use ~just check-incremental true~
or ~just check-debug true~ to print semantic diagnostics only when needed.
Run ~just --list~ for the full
command list. The [[file:Examples/IntegratedPrototype.lean][integrated object example]] follows C4 resolution, lazy execution,
extension, and revision. [[file:Examples/ProofReuseScale.lean][ProofReuseScale.lean]] exercises proof invalidation and reuse;
[[file:Examples/DebugObject.lean][DebugObject.lean]] demonstrates the public tracing API.
[[file:Examples/IncrementalObject.lean][IncrementalObject.lean]] carries unaffected cached values and proof obligations across an inherited source-slot edit, then installs the certified revision in a versioned mutable cell.
