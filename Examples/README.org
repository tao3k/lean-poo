#+TITLE: LeanPoo usage examples

These Lean files show how a caller constructs and uses LeanPoo values. Run a
single scenario with ~lake env lean Examples/NAME.lean~, or run them all with
~just check-example~. Their ~#eval~ output illustrates the API; precise
behavioral assertions belong in [[file:../Tests/README.org][Tests]].

| Scenario | What it shows |
|----------+---------------|
| [[file:MethodDictionary.lean][MethodDictionary]] | C4 inheritance, dynamic dispatch, a caller-selected dictionary, and a preselected method. |
| [[file:LiveRevision.lean][LiveRevision]] | A derived slot before and after a live declaration revision; the old snapshot remains readable. |
| [[file:DebugTrace.lean][DebugTrace]] | Public trace reports for a productive dependency and a recursive read. |
| [[file:LayeredObject.lean][LayeredObject]] | Mix, extend, memoize, clone, and a diamond-shaped inheritance graph. |
| [[file:FirstClassObject.lean][FirstClassObject]] | First-class prototype values and delayed construction. |
| [[file:PrototypeCore.lean][PrototypeCore]] | Open-recursive prototype composition and delayed values. |

The smaller files in this directory introduce one paper operation at a time.
See [[file:../docs/usage.org][API usage]] for the corresponding library entry points.
