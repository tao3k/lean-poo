#+TITLE: LeanPoo tests

The local complete gate runs the 138 independent Lean example/contract files
with resource-capped workers from the canonical Justfile recipes. CI partitions those
same commands across twelve independent file-shard jobs; four bounded diagnostic
files run concurrently with the local atom and document phases after shared
preparation, and in a separate CI job. Python tests in ~tools/tests~ verify exact shard coverage,
preserved bounded arguments, failure/timeout/launch-error propagation and
interruption cleanup. Semantic assertions and proofs remain in Lean.

This directory contains executable assertions and regression cases for the
library. Run ~just check-tests~ for focused contracts or ~just check~ for the
complete project gate. Diagnostic and incremental checks use bounded Lean
processes through ~just check-debug~ and ~just check-incremental~.
