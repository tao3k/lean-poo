#+TITLE: LeanPoo tests

This directory contains executable assertions and regression cases for the
library. Run ~just check-tests~ for focused contracts or ~just check~ for the
complete project gate. Diagnostic and incremental checks use bounded Lean
processes through ~just check-debug~ and ~just check-incremental~.

User-facing scenarios live in [[file:../Examples/README.org][Examples]].

- [[file:SpecificationComposition.lean][SpecificationComposition]] checks fused finalizers, defaults, delayed inheritance, parent-order conflicts, source identity exclusion, and later ancestor insertion.

- [[file:SharedFamily.lean][SharedFamily]] checks shared snapshot composition, declaration authority, metadata and C4 conflicts, and nested absence/error propagation.

- [[file:ClassMigration.lean][ClassMigration]] checks three Person versions, defaults, deleted data, typed renaming/conversion, fresh computations, acceptance certificates, and rejection before source reads.
- [[file:C4Ranked.lean][C4Ranked]] checks whole-graph ancestry ranks, complete structural impact, cycle/reference rejection, and independence from C4 method-order and suffix checks.
- [[file:Renaming.lean][Renaming]] checks reversible heterogeneous slot renaming, internal self reads, delayed inheritance, defaults, duplicate writes, and later extension.
- [[file:AncestryTransform.lean][AncestryTransform]] checks ancestry wrappers, heterogeneous and function-valued slots, unrelated branches, and later extension.
- [[file:TargetPolicies.lean][TargetPolicies]] checks rejection, retained-specification target edits, constant-specification replacement, and target detachment.

- [[file:QuiescentUpgrade.lean][QuiescentUpgrade]] checks admission closure, two concurrent readers draining, exception cleanup, canceled/stale requests, upgrade rollback, and the quiescence and authorization proofs.

- [[file:SortedInheritance.lean][SortedInheritance]] checks two-level sort priorities, complete ordering certificates, same-sort C4 behavior, heterogeneous function slots, future reclassification, and metadata, hierarchy, local-order, and suffix conflicts.
