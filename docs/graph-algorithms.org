#+title: Indexed graph algorithms and Scheme correspondence

* Owners and entrypoints

Generic graph contracts live in LeanPoo; Gerbil Scheme implementations live in
gerbil-poo. Yuanxu owns Module selection, source admission and build/test projection.
Do not make a second loader or cache. The companion gerbil-poo change uses the
existing GeneralizedGraph, StrongComponents, ConstructionCache and publication APIs.

* Sparse dependency order repair

Edges point from consumers to providers. DependencyOrderRepair proves the exact
insertion-cycle condition, bounded searches and incident-edge checks. RankLabels
and HashRankLabels prove stable movement, real HashMap slot assignment, label
permutation, injectivity and outside-owner preservation. StableOrderRepair proves
construction completeness for finite exact frontiers and a valid injective old
order, without assuming that all proposed edges have already passed a checker.
After batch deletions, an insertion prefix inside an acyclic final graph cannot
be refused for a transient cycle. Order intervals never replace value invalidation.

* SCC certificates

ComponentWitness reuses StrongComponents.Reach. Forward/reverse spanning paths
inside groups, plus strictly decreasing ranks across groups, establish exact mutual
reachability. Representative renaming preserves components. The Scheme Tarjan path
checks those structural conditions in linear passes over captured indexed edges.
This is a certificate law, not a theorem about arbitrary native hash complexity,
compiler behavior, callback purity, termination or physical latency.

* Tests and measurement

Tests/GraphAlgorithms.lean participates in the existing contract gate and includes

The Scheme companion retains exhaustive and typed properties, complete graph-family
oracles, phase counters, paired CPU/wall/GC/allocation studies and mutation controls.
Initial metadata preparation, hot queries and full Module EVAL remain separate
measurements. Source/currentness, approval and effect guards remain independent.

* Component index comparison

Finite unique group lists have equal membership exactly when their cardinalities
agree and every old member occurs in the new group. A cached cardinality belongs
to the captured partition index; recomputing a large new group's length for each
old singleton would restore quadratic work.

The component verdict is uniform over an entire old group. One exact comparison
can therefore classify its members together. Missing owners remain changed,
including the case where both lookup results are absent; injective representative
renaming preserves membership. These are pure captured-index laws. They do not
authorize value reuse or omit source/currentness/effect checks.

The companion Scheme optimization is not established by these laws alone.
Its real many-group merges, splits and giant components require native properties
and Benchmark evidence against the existing implementation.

* Size and case dependent Graph research

ComponentWitness now also states concrete HashMap/Array discovery-cell laws,
fresh-slot capacity and separation, shared-frame owner/slot preservation, and
canonical source-order representative equality for independently certified SCC
engines. A conditional plan comparison admits only applicable memory-bounded
plans and includes capture, conversion, discovery, normalization, certification,
decision and switching charges. Omitting conversion is an explicit counterexample.

These laws do not select an empirically fastest engine or install a threshold.
QueueSelection supplies the proof pattern, not an SCC implementation. The POO
100K/1M node workload remains distinct from Yuanxu real-Module EVAL. The dense
state representation is a Scheme candidate; a million-node bounded-degree band
exceeded the existing 2-GiB heap on the prior hash-state implementation. Retain
that failure and qualify case, density, preparation, GC and memory separately.

* Structure-dependent certificate storage

withinGroupEdge retains only edges inside a claimed component. Paths in that
restricted graph are original paths, and restriction commutes with reversal.
A singleton whose owner is itself has both reflexive spanning paths without
reading an adjacency bucket. pruned_spans_keep_certificate retains the complete
cross-group rank obligation and concludes the same exact SCC equivalence.

The Scheme candidate can therefore avoid singleton walks and retain reverse
rows only inside nontrivial groups. Every captured quotient edge is still checked.
After that complete phase, numeric rank storage may be retired into coverage
markers; the concrete HashMap laws prove replacement, numeric-rank refusal and
unrelated-key preservation. They do not prove native liveness or GC behavior.
This is structure-dependent work reduction, not a node-count dispatch threshold.
