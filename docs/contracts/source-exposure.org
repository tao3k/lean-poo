#+title: Private raw storage and published references

* Constructor timing

OwnedSlotSource.raw denotes published raw references, not all physical heap
objects. SourceExposure refines that distinction: stock constructors may run at
their original observation point and their actual records remain in private
storage. Reflection publishes the original address, never creates a replacement
record or invokes a newly installed constructor. Foreign constructors which can
leak a record cannot enter this owned route.

The unpublished fields equal the private captured recipes. Exposure commits the
public-reference boundary before a visitor can receive an address. A raw MOP
writer needs such a reference; it does not cooperatively check a source marker
or announce a revision. expose/write preserve the derived invariant across all
Reachable sequences. issued_private_fields_exact equates complete ordinary
private-field capture with the borrowed recipe array. private_record_control
shows a physically allocated record while no public write is possible.

project maps only published addresses to OwnedSlotSource.raw. issue_projection
and projection_invariant connect the capture laws. Ticket epochs and pending
publication remain OwnedSlotSource's separate control protocol; this projection
does not pretend to implement that whole state machine.

* Scheme correspondence under qualification

The view index contains names and ordinals, not raw records. enumerate and
names_publish_no_reference preserve the entire heap. A missing key preserves
the source exactly. hit_commits_before_delivery returns the original field
after marking its address published; hit_revokes_new_issue derives refusal of
a later private capture. Bounds and exact index/source provenance remain
construction duties, not consequences of finding a name.

The private prototype-map candidate retains its existing specifications shape
and standard compact/RBTree indexes. Its dispatcher closes over an ordinal-only
index and a source exposure function. An internal source-map record from the
existing issuer binds the actual view, dispatcher and source. Authenticate that
registered record and live layout/fields before calling the dispatcher; a
copied receipt cannot authorize another map. This internal record is not a
business observation or a Graph dependency root. No extra registry is created.

Public keys, missing queries and absent removal expose no raw reference.
Public ref, list, for-each, matching contribution folds and filter predicates
commit exposure before a raw value reaches the caller. Names/spines remain
caller-owned copies. Repeated payload access returns the same raw address.
Explicit raw edits and policy conversion currently materialize the ordinary
persistent representation and keep full admission. They are NOT a completed
controlled incremental recipe writer or a locally updated owned-source index.

The local Scheme candidate lives in object/owned-source.scm, included in the
existing object namespace. It keeps copied payload identities and original raw
records inside lexical closures. One internal reference from the existing issuer
binds a fresh symbolic receiver and the source-storage control procedure; no
administrative object, second issuer or source registry is created. Source
operations authenticate the actual registered signature before invoking the
control. A live record binds procedure identity, not a cached decision that the
source is still private. Each new borrow
must inspect the current exposure bit and stock/type frame again.

The candidate preserves all four binding forms. Binding a method executes no
Slot body; opaque business values keep their original identities. Exposing raw
records is atomic under the existing native mutex primitive. Reservations bind
the actual reference, epoch and pending index; abort never restores eligibility.
Raw field mutation changes none of these private counters. Old captures retain
their copied payload identities. An exposed malformed sibling returns to the
original object's complete preparation and is still refused before selection.

This remains a PRIVATE CANDIDATE, not a released interface or an adopted
optimization. The local object<-fun candidate now attempts the view only for
nonempty symbolic keys without parents/defaults and with stock constructors and
no author observation callbacks. Every failed qualification retains the original
rows, constructors and complete preparation. Normal .o is unchanged. The
existing compute-slot-funs path can now install already-admitted generated
thunk rows from a qualified view into its ONE ordinary method table. It keeps
the actual function identities, evaluates no body, and uses independent entry/
return admission. Parents, defaults, declarations, protocols, overrides and
unknown/unowned sources retain complete preparation. Their full constructor/
effect correspondence, controlled edits, native property controls, CPU studies,
Core10K and downstream gates remain required. In particular, arbitrary metadata
method changes must retain the ordinary effect boundary. A controlled recipe
writer and its Graph registration remain open. Preserve the original Gerbil expansion
and author callback checkpoints and the existing QNT effect-window owners.
