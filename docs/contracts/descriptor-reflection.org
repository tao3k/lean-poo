* Update a descriptor through its own description

#+begin_src lean
import LeanPoo.Prototype.DescriptorReflection
import LeanPoo.Prototype.Types
open LeanPoo.Prototype

def renameScore (name : String) : Except String (Descriptor Int) := do
  let element := Descriptor.intRange 0 100
  let fields := DescriptorReflection.description element
  let updated ← fields.set (DescriptorReflection.toRecord element) .name name
  DescriptorReflection.fromRecord updated
#+end_src

The caller writes one typed update. Validation, schema and inspection reuse the
same catalog; users need not maintain separate field lists for each operation.
~selfOf~ describes a descriptor and can itself be passed to ~selfOf~ again.
Names must be nonempty; optional defaults must satisfy both the supplied carrier
refinement and the descriptor's own recognizer. ~fromRecord~ checks field presence;
use ~selfOf.validate~ when also admitting its semantic refinement.

Inspection uses a codec when available and otherwise the descriptor's display.
Schema records field names/types/codec availability. This generates metadata and
presentation. [[file:checked-preparation.org][RecordCodec.prepare]] also generates admitted JSON codecs for fully
codable catalogs. Arbitrary callable serialization and universal function checking
remain outside this interface.
Functions are statically typed; ~checkedCall~ / ~checkedClass~ admit actual results.
Object inspection forces the completed result deliberately, while leaving its
inherited base unforced. Inspecting an unsafe divergent result can still diverge.

* Thread pure values through consumed references

~step old update~ returns a new reference after a successful pure checked update.
Every alias of ~old~ then rejects ~read~ and ~step~. A rejected update preserves
~old~. Pure values already read remain ordinary snapshots; this is capability
consumption, not deep cloning or a static linear ownership type system.
~runPure~ specifies pure value threading; ~run~ executes it through references.
~compose_assoc~ proves checked parent-before-child value composition associative.
The interface does not accept arbitrary effectful callbacks or promise rollback
of external effects. It does not imply an in-place allocation or speedup result.

* Evidence and fixed-point choices

[[file:../../Tests/PaperDescriptorReflection.lean][PaperDescriptorReflection]] guards 101 descriptor/codec contexts, generated
schema/inspection, missing fields, nested self-description, object/meta catalogs,
refinement rejection and an inherited base that remains unforced.
Two exact reconstruction laws are kernel checked. Object reconstruction uses
propext; descriptor reconstruction inherits propext/Classical.choice/Quot.sound
from the existing Descriptor/JSON carrier. No axiom-free blanket claim is made.

[[file:../../Tests/PaperLinearState.lean][PaperLinearState]] guards 64 scalar traces against an independent arithmetic
oracle and 32 races with exactly one successful consumer. Its composition law
uses propext/Quot.sound. [[file:../../Tests/PaperFixedPoints.lean][PaperFixedPoints]] guards 65 recursive inputs and observes
one shared construction versus 32 rebuilding constructions, plus one delayed
non-function construction. ~bottom_apply~ is axiom-free.

Appendix D's invalid eager self reference is not an implementation target.
Internal-define/letrec/lazy routes use the shared Lean thunk knot; untyped Y
self-application is a target-language choice. These controls do not prove
universal Y equivalence, general termination or whole Scheme/Lean semantics.
