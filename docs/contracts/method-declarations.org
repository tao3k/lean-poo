* Gerbil implementation limits

Local methods coalesce only when their policies and visibility agree. Supported source edits invalidate the
registered metadata and receiver graph; raw writes and concurrent mutation remain
outside it. Generic defaults and empty inherited groups catch only their own
receiver/slot absence. Compilation does not run method bodies; invocation sequences
effects without rolling them back. Custom policies require their own laws.
No new argument-based dispatch, arbitrary-carrier fragment macro, optional-formal
grammar, compiler/runtime proof or performance claim is supplied by this bridge.

* Direct combined-generic forwarding

The generic compiler delegates resolved-row construction to the same core
signature projection and standard ~list~ / ~apply~ lowering used by ordinary
calls. It selects the current combination expression, demands the raw inherited
fragment slot, checks that the combiner is a procedure, then directly supplies
both fragments and the complete row. The previous temporary variadic forwarding
procedure is removed. Defaults, predicate contracts and keyword escape semantics
remain owned by Gerbil. Selection/lookup failures retain precedence and identity;
no successful metadata admission is cached across calls.

~FunctionSignature.combineDirect_eq~ proves this relay elimination for arbitrary
monadic effects. The refusal laws and matching top-level examples preserve the
selection/lookup/admission boundaries and the full Reader/qualified-method trace.
The explicit ~CombinationWork~ source-operation model keeps row cells unchanged
and removes one relay closure/call at nonnegative supplied prices. This is not a
compiler allocation theorem: the standard paired Scheme study separately tests
single-operation allocation, hot calls and full Reader/reflection/C3 workflows.
This supports the original article's user-defined method-combination and future
MOP work; it does not replace its method-combination semantics.

* Fixed-prefix row construction

The combined generic now emits the resolved fixed prefix as core ~cons~ forms.
Standard ~append~ with an empty final list copies the rest spine. This replaces
runtime ~apply list~ without sharing mutable argument spines with callers.
Core signature projection, defaults, checks and keyword escape placement are
unchanged. Selection, lookup and combiner admission still precede row construction.
No combiner, fragment or successful admission is frozen across calls.

~assembleRow_eq~, ~assembleRow_length~, ~assembleRow_compose~ and
~combineDirect_assembled~ establish complete-row equality and contextual
substitution for arbitrary monadic combination. ~rowAssemblyCharge_difference~
prices logical row cells, apply/list redistribution and rest copying separately.
This proves neither heap identity nor CPU improvement. Gerbil regression tests
mutate both the prefix and rest spine; the paired study measures transport,
retained workflows, construction plus invocation and fixed-history sensitivity,
with exact A/A controls, natural/collected GC and separate GC/residual CPU deltas.

The implementation budget prices apply/list redistribution and append-based tail
copying separately. ~rowAssemblyCharge_threshold~ proves the conditional transport
criterion. ~rowAssemblyCharge_workflow~ additionally retains construction/setup
and GC history on both sides: cheaper transport cannot by itself establish a
cheaper complete workflow. These are supplied finite cost units; measured CPU
and GC deltas, A/A spread and host interference remain separate evidence.

* Revision-checked contribution admission

The qualifier interpreter from the article remains unchanged. The default Gerbil
~contribution~ constructor now records immutable qualifier/revision evidence in a
standard weak-key table. A matching object and Type revision can reuse that
admission; current descriptor validation handles every miss. Registration is
restricted to the original constructor/Type protocol and finite known symbols.
Evidence contains neither a receiver nor a callback. Supported mutation must
advance the existing transitive revision discipline; direct unsafe record mutation
is outside this premise. Restoring old field values does not restore old revisions.

~admitRegistered_eq~, ~admitRegistered_stale~ and ~admitRegistered_execution~ prove
admission substitution and unchanged subsequent effects under explicit constructor
admission and revision-stability assumptions. ~registered_admissions_eq~ preserves
source order. These laws do not prove Gerbil object mutation, weak-table GC, macro
expansion or runtime speed. Scheme regression controls execute current Type edits,
body/qualifier edits, before-to-primary mutation, and shared-C3 FUN refusal/retry.

~contributionCharge_threshold~ counts registration, repeated guards/checks and
supplied GC history separately. Cold setup or extra collection can outweigh saved
validation. Fair workflow controls use the same current FUN/generic implementation;
only descriptor registration evidence differs. This is an implementation strategy
for the generalized-prototype future work, not an additional article construction.
