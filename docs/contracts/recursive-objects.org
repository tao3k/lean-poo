#+TITLE: Recursive objects, dynamic descriptors and mutable slots

* Recursive computation

[[file:../../LeanPoo/Prototype/Recursive.lean][Recursive]] represents final-self calls as explicit ~Interaction~ syntax.
~close~ composes a prototype with an inherited carrier; ~instantiate~ observes
its function requests. ~instantiateValue~ handles delayed non-function values
and permits a different inherited carrier. ~Observation~ distinguishes
~value~, ~error~ and ~pending~. A pending finite observation is not a proof
of divergence.

[[file:../../LeanPoo/Prototype/RecursiveSemantics.lean][RecursiveSemantics]] defines unbounded ~Evaluates~ derivations. Every completed
finite observation has a derivation, and every derivation completes at some
finite depth. ~diverges_iff_no_evaluation~ characterizes programs that remain
pending at every depth. ~solve_relation~ transfers observations between
related carriers at every depth, preserving errors and pending outcomes.
~solve_le_fixed~ gives refinement into any fixed observation satisfying the
program equation. These proofs require no unsafe execution assumptions.

The declared language is the explicit recursive interaction calculus. Arbitrary
Scheme evaluation and arbitrary unsafe shared-thunk execution are outside its
kernel correspondence theorem. [[file:../../Tests/RecursiveSemantics.lean][RecursiveSemantics controls]] compare thirteen
factorial inputs with the shared runtime and prove factorial carrier transfer
and a diverging self loop.

[[file:shared-thunks.org][Checked shared-thunk execution]] now compiles this declared interaction language
through the existing native knot. Its demand traces have a safe operational
equivalence theorem, and successful safe admission binds the actual executor's
reported result to the current program. Native IO/thunk implementation and
arbitrary unsafe callback equivalence remain outside that theorem.

* C3 object construction

[[file:../../LeanPoo/Object/SlotSyntax.lean][SlotSyntax]] composes actual declarations in precedence order. Its
~resolveForward_eq~ proves equality with reversed, parent-first assembly for
every key and final self. ~Plan.slotSyntax_resolve~ connects the existing
C4 resolver to this composition. [[file:../../LeanPoo/Object/C3.lean][Object.C3]] exposes ~compileC3~ and certifies
that any source-style C3 derivation yields the same typed slot result.

[[file:../../LeanPoo/Object/Recursive.lean][Object.Recursive]] joins C3 ordering, effective dynamic slots and the safe
recursive observer. Compilation checks topology and prototype errors. A
~Plan~ retains the actual order and assembled storage; ~read_derivation~
proves object observations agree with any C3 derivation for every depth and
key. ~read_returns~ and ~read_diverges~ connect those reads to the unbounded
operational semantics. ~Plan.mutable~ allocates a fresh mutable identity from
the certified storage. C3 and C4 are explicit policies with separate APIs.

* Runtime descriptors

[[file:../../LeanPoo/Prototype/DynamicDescriptor.lean][DynamicDescriptor]] supplies a recursive ~Value~ universe, first-class
registered functions/descriptors and contracts for primitives, ranges, lists,
dictionaries, objects, named recursive types, unions and intersections.
Membership validates identities against the supplied current registry.
Budget exhaustion is an error. ~Descriptor.call~ checks both argument and
result contracts; [[file:../../LeanPoo/Prototype/DynamicDescriptorSemantics.lean][DynamicDescriptorSemantics]] proves successful membership
and call admission against an inductive ~Accepted~ relation.

~Contract.describe~ exposes constructors and arguments as ordinary dynamic
objects. ~Registry.inspect~ resolves descriptor values and returns their
contract, name and open metadata. Function membership establishes registered
callability; behavioral refinements are checked on calls. It does not decide
universal properties of arbitrary functions or serialize closures.

* Mutable protocol and conversions

[[file:../../LeanPoo/Prototype/MutableRecord.lean][MutableRecord]] stores effective slot computations in one mutex-protected hash
identity. ~Specification~ supports identity, slot, composition and error.
Parent mutations precede child mutations. Each slot write captures inherited
syntax, receives explicit final self, and performs one table insertion;
subsequent self reads see the current storage. An override can skip inherited
errors. Failure retains earlier writes and skips subsequent mutations.

~Specification.interpret~ is the shared parent-first interpreter; ~transition~
and ~snapshotTransition~ specialize its state writes. [[file:../../LeanPoo/Prototype/MutableRecordSemantics.lean][MutableRecordSemantics]] proves
soundness, completeness and uniqueness against an independent ~Executes~
relation. Representation projection retains the complete state and status;
snapshot and linear observations agree at every key and depth.

All three carriers retain writes before the first error and skip later writes.
A failed linear operation keeps the old aliases valid with that partial state;
it can resume. Success consumes the old aliases and returns a fresh reference.
The paper does not specify rollback; this is the common repository convention.
~snapshot~, ~create~, ~fromValues~ and ~applyLinear~ expose the conversions.
Mutable application commits the complete specification under its existing
mutex, advances the generation per write and invalidates memo entries after
any write, including writes before an error. A no-write failure retains the
snapshot and memo. [[file:../../Tests/MutableRecordSemantics.lean][616 protocol scenarios]] include 376 failures, four selected
keys and four depths, alias visibility, retained snapshots and failure resume.
These concrete IO controls accompany the kernel interpreter/projection laws.

* Shared lazy execution and descriptor integration

[[file:../../LeanPoo/Prototype/RecursiveCache.lean][RecursiveCache]] evaluates final-self requests by need. Each cache entry
contains an unbounded evaluation proof for the exact indexed program.
Completed values and source errors are shared; active requests produce cycle
paths. Budget exhaustion and cycles remain separate diagnostics. A cached
receipt agrees with every completed finite source observation. The machine
budget bounds recursion depth, including administrative continuations; it is
not the observer's self-call depth or a machine-time limit.

[[file:../../LeanPoo/Object/RecursiveInstance.lean][RecursiveInstance]] gives a fresh, initially unforced identity. Mutex-protected
reads serialize concurrent aliases. MutableRecord.force retains a receipt for
the exact read snapshot; writes clear the memo and advance the generation.
Escaped snapshots remain immutable. The controls compute Fibonacci(40) with
41 distinct input misses, test concurrent sharing, cached errors, cycle paths
and mutation invalidation. These are work counters, not a timing claim.

[[file:../../LeanPoo/Prototype/DynamicSchema.lean][DynamicSchema]] registers descriptors built from runtime type/value parameters.
One SlotDescription catalog generates defaults, inspection, ordered updates
and a reconstructible schema. Sealed records reject extra fields; read-only
fields and invalid refinements are refused. Empty patches still validate the
input, and rejected pure patches do not publish earlier partial edits.

[[file:../../LeanPoo/Prototype/DynamicCodec.lean][DynamicCodec]] preserves exact integers, Unicode, ordered/duplicate raw
entries and registered identities in a tagged array format. Text/byte admission
checks nested identities in the current registry and returns an Accepted proof.
Functions serialize identities, not closure code. Structural JSON now has a
universal kernel inverse at Value.wireDepth. Text/byte round trips remain
execution controls; general text-parser and UTF-8 inversion are separate claims.

[[file:../../LeanPoo/Object/RecursiveValidation.lean][RecursiveValidation]] materializes requested actual object fields with their
kernel evaluation proofs, then admits those same values through the runtime
schema. Open schemas leave unrelated cyclic slots cold; sealed schemas reject
extra stored slots without forcing them. Source errors, cycles, exhaustion
and descriptor refusals remain distinguishable.

* Complete shared evaluation and dynamic recognition

[[file:../../LeanPoo/Prototype/RecursiveCacheSemantics.lean][RecursiveCacheSemantics]] proves run_iff_evaluates for every program/request and
sound warm cache. Every finite operational value/error derivation completes at
some machine budget. diverges_iff_no_run characterizes absence of successful
machine executions, and run_cycle_diverges admits actual cycle diagnostics as
divergence proofs. Exhaustion alone remains inconclusive. These proofs do not
give wall-time or allocation bounds.

Instance.readCertified returns a Failure indexed by the plan and requested key.
Mutable.forceCertified returns the exact immutable snapshot for either success
or failure. A cycle contains its Diverges proof; an exhausted budget contains
no impossibility claim. Ordinary read/force expose the same diagnostics through
the checked execution path.

[[file:../../LeanPoo/Prototype/DynamicDescriptorCompleteness.lean][DynamicDescriptorCompleteness]] proves that every finite Accepted derivation
is recognized at all sufficiently large depths, including recursive named
types. A successful union branch determines membership despite an unresolved
alternative. An unresolved branch remains an error when neither succeeds.
This describes finite inductive membership, with callable identity recognition
and separately checked function input/output boundaries.

[[file:../../LeanPoo/Prototype/DynamicCodecSemantics.lean][DynamicCodecSemantics]] proves decodeJson_encodeJson for every dynamic value.
wireDepth is computable and depends on nesting, not numeric magnitude or text
length. Descriptor.json_roundTrip preserves the actual admitted value/proof in
the same registry at sufficient decoder depth.

* Parameterized object methods

[[file:../../LeanPoo/Prototype/CallableRecord.lean][CallableRecord]] extends a final-self request to a method name and an
argument. A method layer receives final self and a delayed inherited method;
it can call either with different arguments. The ordinary Proto/composeAll
operations assemble these layers. The existing recursive machine evaluates
them; the complete name/argument pair is its sharing and active-cycle key.
Calling the same method with a different argument does not itself prove a cycle.

[[file:../../LeanPoo/Object/Callable.lean][Object.Callable]] compiles these methods in the certified C3 order. A fresh
instance leaves all methods cold, and aliases share one mutex-protected cache.
Every successful value/error receipt is indexed by the actual method program.
callCertified retains the divergence proof and parameterized path of a cycle;
budget exhaustion remains inconclusive. call_derivation proves agreement with
any source C3 derivation at every depth and argument.

Plan.fromFields admits existing data objects using a distinguished field
argument. [[file:../../LeanPoo/Prototype/RecursiveReindex.lean][RecursiveReindex]] proves observation and unbounded evaluation
preservation under this request transformation. call_fromFields preserves
every original read, including source errors and pending observations.

[[file:../../LeanPoo/Prototype/DynamicValueEquality.lean][DynamicValueEquality]] supplies computable structural DecidableEq for
dynamic arguments, justified by equalAt_correct at Value.wireDepth. Exact
integers, Unicode, ordered entries, duplicate raw fields and reference
identities remain distinct; the cache trusts no hash or unchecked comparator.

[[file:../../LeanPoo/Object/CallableValidation.lean][CallableValidation]] applies runtime FunctionOf descriptors and reflective
SlotDescription catalogs directly to these methods. Inputs are checked before
forcing. Outputs, including cached results, pass the current registry gate on
every invocation. CheckedCall retains the actual evaluation and input/output
Accepted proofs. Mutable.invoke returns the exact retained snapshot with those
proofs; replacements clear all argument results and advance its generation.

[[file:../../Tests/CallableObjects.lean][Callable controls]] cover the paper's numeric self/super layers, C3 diamond
composition, inherited argument forwarding, Fibonacci(40) with 41 misses,
concurrent aliases, cold cyclic methods and mutable final-self rebinding.
[[file:../../Tests/CallableValidation.lean][Boundary controls]] check runtime factories/catalogs, refusals before forcing,
current-registry revalidation of hot results and snapshot-bound mutable calls.
This protocol is the explicit interaction calculus with Lean argument carriers;
it supplies neither arbitrary Scheme closure execution nor machine cost bounds.
