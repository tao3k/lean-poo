* Declared semantics

The paper supplies executable Scheme/Scribble constructions and mathematical
explanations. The Lean correspondence scope is explicit: typed composition,
recursive interactions, C3 graph derivations, dynamic contract admission and
specified state transitions. The ~whole_paper_implemented~ flag stays false:
arbitrary Scheme programs, all unsafe execution and unrestricted automation
are outside these theorems. The explicit future proposals remain research.

* Reusable evidence

[[file:../../../LeanPoo/Prototype/RecursiveSemantics.lean][RecursiveSemantics]] uses a finite derivation for each completed evaluation.
The observer is sound and complete for that relation. Completed observations
remain stable as depth increases; the semantic divergence predicate quantifies
over every depth. [[file:../../../Tests/RecursiveSemantics.lean][RecursiveSemantics controls]] prove a diverging loop and
all-depth Nat/Int factorial correspondence, and compare thirteen concrete
inputs with the separate unsafe shared-thunk runtime.

[[file:../../../LeanPoo/Prototype/C3DAG.lean][C3DAG]] proves cached/reference equality by induction on production fuel,
using ranks to rule out active-path cycles and preserved derivation-backed
cache entries to justify hits. Its theorem includes complete ~Except~ results.
[[file:../../../Tests/C3DAG.lean][C3DAG controls]] include deep shared ancestry, repeated
roots, missing roots, missing parents and inconsistent orders.

[[file:../../../LeanPoo/Prototype/C3CacheCoherence.lean][C3CacheCoherence]] now proves complete cached/reference scalar and batch
~Except~ equality for every finite graph and root list. An edge below a successful
derivation strictly decreases its unique order length, so a finite derived cache
value cannot lie on an ancestry cycle. ~ActivePath~ retains declared, distinct
ancestors and their actual nonempty walks to the current node. That invariant
and the graph-size remaining budget prove reference completion at every sound
hit. The parent loop preserves cache derivations and exact first errors, then
the existing batch lifting theorem supplies arbitrary empty/repeated root lists.
No DAG witness or successful-result premise is required by the public equality.

[[file:../../../Tests/C3CacheCoherence.lean][New controls]] compare 4913 graphs, 34433 batches and 14739 warm reads to an
independent scalar oracle, including 20795 cyclic batches and 2364 hot root hits.
They retain missing/merge errors and validation priority. Forged cache entries,
insufficient fuel and fabricated active paths discriminate the internal theorem's
necessary hypotheses. The universal result concerns the actual production
budget and sound current-graph caches; it asserts no arbitrary-cache or arbitrary-
fuel equality and no unrestricted Scheme/Lean language equivalence.

[[file:../../../LeanPoo/Object/Recursive.lean][Recursive objects]] assemble storage using the certified C3 order and read it
through the same safe recursive semantics. [[file:../../../Tests/ObjectSemantics.lean][Object controls]] cover inheritance,
override, inherited modification, final-self slot dependencies, errors,
pending observations and mutable conversion. The typed C3 object API also
connects to the same declaration semantics used by the C4 resolver.

[[file:../../../LeanPoo/Prototype/DynamicDescriptorSemantics.lean][Dynamic admission]] proves positive membership and successful checked calls.
Function membership recognizes registered callability; input/output behavior
is checked at application. It is not a universal function-property decision.
Mutable IO behavior is checked against the pure transition on representative
compositions, including partial errors; there is no unrestricted kernel IO
refinement theorem or machine-level cost guarantee.

Earlier [[file:../../../LeanPoo/Prototype/FiniteFix.lean][finite fixed-point certificates]], [[file:../../../Tests/RecordDispatch.lean][checked x/y records]] and
[[file:../../../Tests/RecordComplexRelation.lean][complex-coordinate records]] retain their narrower correspondence scopes.
The new operational calculus supplies the general recursive proof surface.

* Source execution

~tools/poof_source_check.py~ verifies source identity and executes balanced
Definitions/Examples/Checks blocks with the Racket reader. The checked fixture
is an exact extraction from the original paper; code is not imported into the
library. Fail-fast check macros retain canonical source outcomes.
[[file:../../../Tests/SourceDifferential.lean][SourceDifferential]] computes every mapped Lean observation, and the comparator
rejects mismatches, omissions and duplicate check identities. CI runs this
comparison and requires its job to succeed. Local Racket 9.0 passed all
24 comparisons. This example gate is distinct from whole-language equivalence.

* Shared execution and generated dynamic tools

RecursiveCache now memoizes values and source errors with kernel evaluation
receipts for the exact immutable program. RecursiveInstance serializes aliases
and leaves unread slots cold. Mutable writes clear cached computations and
advance snapshot generations. Runtime cycle paths are separate diagnostics,
not fabricated source-error derivations or a divergence claim from exhaustion.
DynamicSchema supplies registered runtime dependent factories and field-owned
defaults, inspection, updates and reconstructible catalogs. DynamicCodec admits
text/bytes through nested current-registry identity checks and Accepted proofs.
RecursiveValidation attaches the actual C3 field evaluations to those same
schema/wire values. General unsafe-thunk correspondence and unrestricted IO
refinement remain separate proof questions.

* Execution and admission completeness

RecursiveCacheSemantics proves that every finite operational value/error
derivation completes at some machine budget from any sound cache. Successful
results and reported cycles are stable under larger budgets. A reported cycle
therefore proves source divergence; exhaustion alone still proves neither
divergence nor impossibility. readCertified and forceCertified return these
proofs for the exact plan/request or retained mutable snapshot.

DynamicDescriptorCompleteness proves membership iff recognition at some depth,
and recognition at every sufficiently large depth. Union membership succeeds
when either branch succeeds, even if the other exhausts its depth or refers to
an unavailable descriptor. When neither succeeds, unresolved diagnostics remain
errors rather than fabricated rejections.

DynamicCodecSemantics proves structural JSON inversion for every Value when
fuel reaches its computable wireDepth, including exact integers, Unicode and
ordered duplicate entries. A descriptor-admitted value and its Accepted proof
re-enter the same fixed registry gate. General JSON text-parser and UTF-8 inverse
proofs and machine-level resource bounds are not supplied by this theorem.

* Parameterized method execution

CallableRecord stores method functions receiving an argument and explicit
final-self requests; inherited methods remain delayed and can receive different
arguments. Object.Callable composes them with the existing Proto operations in
the certified C3 order. Calls use the existing RecursiveCache machine, keyed by
the complete method name and argument. A repeating name with changing arguments
is not an active cycle. Certified cycles retain the complete request path and
the exact program's divergence proof.

RecursiveReindex and Plan.call_fromFields preserve every value-only object
observation when its field requests enter this protocol. DynamicValueEquality
proves the computable argument comparator correct for every dynamic value at
its structural depth; cache equality needs no registry, wire parser or hash.

CallableValidation uses runtime FunctionOf descriptors and reflective slot
catalogs as actual method calling conventions. Inputs validate before forcing;
hot outputs still pass current-registry checks. CheckedCall retains the actual
evaluation and both Accepted proofs. Mutable calls expose their immutable
snapshot, and replacement clears every argument result. Controls include
numeric self/super calls, C3 diamonds, argument forwarding, concurrent sharing,
source errors, changing-argument recursion, and refusal after registry changes.
Unrestricted IO refinement and arbitrary Scheme closure correspondence remain
outside these stated theorems.

* Explicit negative Functional assumptions

[[file:../../../LeanPoo/Functional/Absence.lean][Absence]] proves complete admission/refusal for an arbitrary dependent
provider/key family. Every refusal carries the first present factory and an
exact absent prefix. [[file:../../../LeanPoo/Functional/GuardedExtension.lean][GuardedExtension]] proves acceptance exactly when the
underlying pure transaction succeeds and its final assembled snapshot preserves
all watched absences. Disjoint scopes retain the old proof by exact per-key
selection preservation. Conflict factories have actual graph provenance.
[[file:../../../Tests/FunctionalAbsence.lean][FunctionalAbsence]] checks 570 independent state cases and a divergent
factory that must remain unforced. The first-missing preparation control shows
why preserving one cached error cannot prove absence of every later key.

[[file:functional.org][The question map]] distinguishes these explicit contracts, existing
consumer machinery, local witness-transport extensions and broader unresolved
questions. The provider-transaction policy retains a fixed graph/order;
[[file:../../contracts/graph-migrations.org][Graph migration]] now admits arbitrary verified target topology/root changes
and joins positive/negative contracts with cache revision. It retains the
context/key/value family and explicit watched lists. The analyzed computation
extension below also infers finite pure dependencies and guards. Arbitrary
closure introspection and a universal cross-library conflict policy remain open.

* Verified graph migration and constraint caches

[[file:../../../LeanPoo/Functional/GraphMigration.lean][GraphMigration]] compiles the actual target graph/root, retains complete overlays
for surviving names, installs new providers and completes all requested edits.
Its acceptance theorem characterizes actual compilation and transaction success.
The computed reuse decision proves exact preparation equality when first winning
identities remain equal and target ancestry/key edit scopes are disjoint.
No host function equality is tested.

[[file:../../../LeanPoo/Functional/GraphConstraints.lean][GraphConstraints]] proves complete acceptance exactly for watched absences and
available positive factories on the completed target. A negative refusal contains
the actual first present factory; a positive refusal proves the exact missing
error. Stable success retains arbitrary joint proof and the exact hot context
slot. Fresh success requires new joint admission, starts an empty slot and uses
the already prepared factories. Certified availability prevents publication of
a missing positive requirement. These laws hold for arbitrary dependent families.
The [[file:../../../Tests/FunctionalGraphMigration.lean][660 migration controls]] and [[file:../../../Tests/FunctionalGraphConstraints.lean][6300 constraint/cache controls]] include changed
roots, deletion/fallback, new reachability, suffixes, retained overrides, repeated
keys, chained migrations and nonterminating factories that must remain unforced.

* Inferred pure dependencies and computed output caches

[[file:../../../LeanPoo/Functional/DependencyAnalysis.lean][DependencyAnalysis]] automatically collects value/presence reads and required/forbidden
guards from typed finite pure computations, including nested helpers and both
conditional branches. Its congruence theorem proves actual value/error equality
at every context under preserved observations. Satisfied inferred guards prove
capability safety for known syntax; source errors retain their ordinary meaning.
Provider-wide callbacks carry an unknown footprint, including within dead branches.

[[file:../../../LeanPoo/Functional/AnalyzedMigration.lean][AnalyzedMigration]] expands the existing positive/negative graph gate with those
inferred guards and proves complete acceptance for the conservative static policy.
Its reuse decision compares exact selected value factories and final availability
observations, then proves universal equality of actual computation. A reused
[[file:../../../LeanPoo/Functional/AnalyzedCache.lean][computed cache]] retains its result proof, stored value/error and exact hit decision
through the existing ContextSlot. Affected or unknown computations store no old
slot and require fresh result admission. Raw capability preparation and computed
results have independent lifetimes, preventing hidden optional reads from retaining
a stale output after explicit positive selection remains stable.

The [[file:../../contracts/dependency-analysis.org][API guide]] records fixed body/family indices, conservative conditional contracts
and the unknown-callback boundary. The new clients check 1536 scalar observations,
9616 stable-footprint comparisons, 28 cache reads and 1792 actual graph migrations
(330 reused, 514 fresh, 948 refused), plus divergent-presence and branch-conflict
controls. Arbitrary-language dependency/effect/termination inference remains open.

* Automatic typed dictionary/class correspondence

[[file:../../../LeanPoo/Deriving/DictionaryCompiler.lean][DictionaryCompiler]] generates dependent field carriers and both conversions
from actual Type-valued Lean structure/class constructors. Every generated
roundtrip proof is checked against those functions by the kernel. Inherited
subobjects, dependent Type/Sort/data/proof fields, functions, instance parameters
and universes remain intact. Nonstructures, Prop-valued classes, unsupported
indexed constructors and collisions are refused without a partial schema.

[[file:../../../LeanPoo/Prototype/DictionaryBridge.lean][DictionaryBridge]] proves exact bidirectional conversion of existing typed
self/super prototypes and delayed prototypes. Actual composition, every finite
unfolding and fixed-point equations commute. Typed Descriptor validation,
display/default and optional codecs preserve values and error/refusal outcomes.
[[file:../../../LeanPoo/Functional/DictionaryTransport.lean][DictionaryTransport]] proves actual first-provider/C4 assembly and requirement
preparation correspondence, including first missing keys. Existing joint proofs
and ContextSlot data/hit decisions survive representation conversion.

The [[file:../../contracts/dictionary-classes.org][guide]] links generic proof clients and native controls: nine constructor
shapes, 1024 arithmetic dispatches, 33 polymorphic calls, 1280 self/super calls,
2304 finite unfoldings, descriptor admissions/refusals, retained lazy terminal
overrides and sixteen actual graph/constraint migrations. This closes typed
Lean constructor correspondence. General Scheme compilation, dynamic closure
reflection/serialization, unrestricted unsafe fixed-point/IO equivalence and
machine-level time/allocation bounds remain outside the declared theorem scope.
