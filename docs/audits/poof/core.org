These implement bounded Lean forms of the constructive nucleus. They do not

safe composition laws also do not prove termination of unsafe instantiation.

* Partial behavior and test correspondence

Paper basic checks (322–378) and Appendix A checks use expected values.
~RecordPrototype~ and several other current Examples instead print values via
~#eval~. Successful elaboration/evaluation alone does not reject an incorrect
expected answer. A complete case map must identify each paper check, its
typed Lean input, expected observation and assertion, including order changes.

The Bottom discussion (583–632) mixes missing-field error behavior, arbitrary
computations and divergence. LeanPoo exposes Option reads, typed callbacks and
unsafe recursive computations. These are documented interfaces, but no common
operational model relates all three to the paper's untyped bottom.

* Missing complete Order → BST → AVL case

| Paper lines | Missing case | Required closure evidence |
|-------------+--------------+---------------------------|
| 674–736 | Number/string/symbol order prototypes and compare mixin | Same open self-based comparison/delegation and all paper outcomes |
| 737–799 | Binary-tree dictionary | node/singleton/acons/ref/afoldr composed through the prototype; missing-key path and ordered-key skew case |
| 800–845 | AVL extension | Override only node construction; retain inherited dictionary algorithms; rotation, height and five-entry lookup controls |

No corresponding end-to-end implementations were found in the reviewed 286
Lean source filenames and targeted source searches. An ancestry/order theorem
in C4 is not a number/string comparator, and a Std.HashMap backing table is not
the paper's open-recursive binary-tree/AVL extension. The absence judgment is
manual source review, not a proof obtained by searching one identifier.

This is the clearest concrete gap in the original executable paper path.
Adding unrelated reusable functions cannot close it. A standalone AVL library
would also be insufficient unless it demonstrates the inherited-method override
mechanism and reproduces the source case outcomes.
