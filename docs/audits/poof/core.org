* Source checks and bottom boundary

[[file:checks-v1.json][All 24 source checks]] map to typed assertions in PrototypeChecks, Trees
and C3. Complex source literals use integral coordinate pairs; dynamic
homogeneous-list tests use a JSON boundary. The original 76 code blocks now execute in Racket and all 24 canonical outputs compare against computed Lean observations.
The map establishes bounded source cases, not general cross-language equivalence.

The Bottom discussion mixes missing-field errors, computations and divergence.
Option/Except and unsafe fixed points implement separate Lean interfaces;
CheckedFunction now supplies explicit bottom, default-base instantiation and
constant-tail bypass. Recursive now gives separate return/error/pending observations with sound/complete unbounded evaluation for its explicit interaction calculus.

* Safe recursive API

[[file:../../contracts/recursive-objects.org][Recursive objects]] documents function and delayed-value instantiation,
heterogeneous inherited carriers and related-carrier observation transfer.
~solve_sound~ and ~solve_complete~ connect finite observations to unbounded
evaluation; divergence quantifies over all depths. This is the declared
recursive calculus, rather than a claim about every Scheme program.

* Actual parameterized object methods

[[file:../../../LeanPoo/Object/Callable.lean][Callable]] connects method name/argument requests to actual C3 construction.
Both final-self and delayed inherited methods can receive new arguments.
[[file:../../../Tests/CallableObjects.lean][CallableObjects]] executes the paper's even/cube numeric layers, C3 diamond
composition, argument forwarding, shared Fibonacci recursion and mutable
replacement. The existing evaluator owns all execution and cache receipts.
The generic argument carrier can be a Lean type or the recursive dynamic Value
universe. A kernel theorem preserves every existing value-only object read
when it enters this protocol. Runtime FunctionOf descriptors and catalogs
validate actual calls, with current-registry checks on hot results.
