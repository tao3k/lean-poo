* Research extension

[[file:contracts/generalized-prototypes.org][Generalized prototype protocol]] separates raw storage, cooked self and fragments, with explicit inheritance, lens, representation and closure contracts.

[[file:contracts/generalized-components.org][Mounted generalized components]] joins local closure witnesses, preserves local fragment orders and retains the left public interface under certified right replacement.

[[file:contracts/generalized-dependencies.org][Directional generalized dependencies]] indexes downstream closure by an explicit upstream view and admits reuse only with equality evidence for that dependency.

[[file:contracts/generalized-chain.org][Multi-level generalized dependencies]] sequences typed closure admission and selected-view refresh along finite heterogeneous chains, with whole closure obtained by nested existing dependent mounting.

[[file:contracts/generalized-fork.org][Shared upstream and exact joins]] reuses independent component closure and selected dependency refresh for explicitly declared fork/join shapes, with exact paired join indices and full-interface preservation.

[[file:contracts/generalized-context.org][Shared context through multiple joins]] composes fork input projections and admits contextual joins using the complete new context/branch key, with a reusable seven-component Functional workflow.
