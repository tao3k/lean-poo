#+TITLE: LeanPoo benchmarks

These programs measure C4 traversal, declaration construction, dispatch,
layout lookup, revision, memoization, and mutable composition. Run a named
~just benchmark-*~ recipe; these measurements are separate from the project
test gate. They do not establish a general performance guarantee.

~just benchmark-strict-definition~ compares ordered replacement construction
with duplicate-checked construction on distinct keys at three scales.

~just benchmark-schema-merge~ compares repeated pairwise merging with the
shared-index pass over disjoint families. It checks node counts and inherited
declaration checksums before reporting timings.

Usage scenarios live in [[file:../Examples/README.org][Examples]], and assertions live in
[[file:../Tests/README.org][Tests]].

~just benchmark-check-startup~ compares repeated Lake launches with batched
cached builds and an already configured Lean environment. It alternates A/B
order over three repetitions, requires identical Lean check transcripts, and
reports CPU and wall time separately. ~CheckStartup.py --output receipt.json~
saves samples and exact Lean-source hashes. These are warm pipeline startup
measurements, not C4 algorithm throughput or a whole-suite speedup claim.

See [[file:../docs/check-performance.org][check pipeline performance]] for the measured boundary and full gate policy.
